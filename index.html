🌐 MULTI-PC REALTIME CLOUD SYNC (FIREBASE DATABASE URL)

To connect multiple factory PCs in real time: create a free Realtime Database at console.firebase.google.com, copy the URL (e.g. https://your-project-default-rtdb.firebaseio.com) and paste it below on each PC.

⚠️ Security warning: a Firebase Realtime Database created in Test Mode accepts reads and writes from anyone, from any PC that knows this URL — including strangers. Anyone with the URL can read all production data and can write/alter it. Before putting real production data in it, switch the database to Locked Mode and configure authentication rules. See the README for the exact rules.
